# TimeWise · Desktop

**Proposta de um gerenciador pessoal de tempo em Python.**

Este repositório está na etapa de organização da versão desktop do TimeWise. A proposta registrada é usar **Python e CustomTkinter** para reunir agenda automática, quadro Kanban e relatórios em PDF.

## Estado atual

O código-fonte da aplicação ainda não foi publicado aqui. As funcionalidades acima descrevem o escopo planejado; ainda não há instalador, demonstração ou instruções de execução para esta versão.

## Procurando código para explorar?

A versão web tem seu próprio repositório: **[TimeWise Web](https://github.com/kenzomatsui/timewise-web)**, com frontend em React, backend em Encore.ts, tarefas, compromissos e alocação de agenda.
